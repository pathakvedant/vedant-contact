This is an independent program built from textbook formulas. It has no link to any fan software vendor and uses no vendor's data or code. The three built-in fan designs are invented for teaching.

Selection

Test data is converted to coefficients that do not depend on size or speed. For each size, the program finds where the duty's system curve crosses the fan curve, using a shape-preserving curve through your test points.

φ = Q / (n D³) ψ = P / (ρ n² D²) n in rev/s Solve ψ(φ) / φ² = P D⁴ / (ρ Q²), then n = Q / (φ D³) Shaft power = Q P / η Tip speed = π D N / 60

Gas density

p = 101325 (1 − 2.25577×10⁻⁵ h)^5.25588 ρ = p / (287.05 (t + 273.15))

Motor and start

The motor is sized on the larger of hot and cold-start power, plus your margin, then rounded up to the next IEC rating. Starting time uses average torques, and fan torque is taken as rising with speed squared. Check it against the motor maker's curves.

t = J ω / (T_motor,mean − T_fan / 3) J referred to motor = J_fan (N_fan / N_motor)²

Shaft, critical speed and tip stress

These simple estimates ignore shaft weight, bearing flexibility and belt pull. The 40 MPa default is a common limit for shafts with a keyway. Impeller stress here is a thin-ring figure, and a real impeller needs proper stress analysis.

Overhung: δ = W a² (L + a) / (3 E I) Centre hung: δ = W L³ / (48 E I) I = π d⁴ / 64 N_c = (60 / 2π) √(g / δ) d_min = (16 T / (π τ))^(1/3) σ_tip = ρ_steel u²

Noise

Overall sound power and octave corrections come from Engineering Toolbox, which advises using maker's data for exact levels. Sound pressure assumes one fan over a hard floor with no room effects.

L_W = 40 + 10 log Q + 20 log P L_p,A = L_W,A − 20 log r − 8

Weights, cost and drawing

Weights use simple plate-area rules of thumb, so treat them as first guesses. Cost is your rates applied to those weights. The drawing shows a typical scroll shape, and it is not a designed casing.

What it does not do

  • Design aerodynamic shapes. Enter proportions and curves you have tested.
  • Correct between static and total pressure. Keep the duty and test data on one basis.
  • Check bearing life, belt loads, fatigue, balancing or high-temperature material strength.

The calculation engine has an automated test suite, but no fan built from these results has been tested.
